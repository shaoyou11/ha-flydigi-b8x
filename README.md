# Flydigi B8X BLE

通过 Home Assistant 蓝牙适配器或 ESPHome 蓝牙代理，本地接入飞智 B8X 手机散热器。
非官方项目，与飞智无隶属关系。目前仅在 B8X 上完成实机验证，不保证其他型号兼容。

## 功能

- 读取冷面温度、热面温度和实际风扇转速。
- 灯光开关。
- 自动调节、手动固定两种运行模式。
- 风速设定：4000–4500，步长 100。
- 制冷设定：92–175，协议原始档位，不是温度、瓦数或百分比。
- 蓝牙连接开关：暂停 HA 访问，方便连接官方 App。

自动模式下，风速和制冷设定限制自动调节的上限；手动模式下，用于设定固定档位。
“风扇转速”是实际测量值，不等于设定值，不能根据两者的差异直接判断控制失败。
每次写入前读取真实状态，写入后等待设备回包确认；超时会报错，不乐观更新状态。

## 安装与更新

需要 Home Assistant 2026.3 或更新版本，以及可主动连接的蓝牙适配器或代理。

1. 在 HACS 的“自定义存储库”中添加本仓库，类型选择“集成”。
2. 下载 Flydigi B8X BLE，按 HACS 提示重启 Home Assistant。
3. 在“设置 → 设备与服务 → 添加集成”中搜索 Flydigi B8X BLE。
4. 输入 B8X 的蓝牙 MAC 地址。配置存储在本机，不上传到仓库。

更新通过 HACS 下载 GitHub Release，保留原有配置和实体唯一标识。
本仓库支持 HACS 自定义存储库安装，不代表已经进入 HACS 默认列表。

## 与官方 App 共用

在 HA 中关闭“蓝牙连接”，等当前会话释放后再连接官方 App。
调整完成后，断开官方 App，再开启 HA 的“蓝牙连接”。此开关不会关闭散热器。
集成每 120 秒短时读取一次，操作完成后断开；不会持续占用连接，也不无限扫描。

## 限制与安全

- 只开放已验证的自动、手动模式；不开放超频、升级固件、恢复出厂或关闭温度保护。
- 制冷档位尚未标定成实际功率，因此不显示为 W 或百分比。
- 协议中的基础档位采用官方 B8X 页面使用的 92 / 4000，模式切换保留当前上限和目标温度。
- 仅温度、转速、灯光、模式和有限范围的档位控制完成验证；没有散热器主电源开关。
- 请保留设备原有温度保护，并注意低温凝露风险。
